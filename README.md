- Unity/C# 기반 실시간 콘텐츠 개발
- 사용자 입력, 충돌, 상태 전환 및 상호작용 로직 구현
- AR Foundation 기반 이미지 마커 추적과 데이터 기반 오브젝트 배치
- Three.js 기반 브라우저 3D 게임과 뷰어 구현
